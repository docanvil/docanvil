# Bundled syntax definitions

`TOML.sublime-syntax` comes from [Sublime HQ Packages](https://github.com/sublimehq/Packages/blob/f29821e2f98f5fde8aa4a956676c770407bf15cc/TOML/TOML.sublime-syntax), pinned to commit `f29821e2f98f5fde8aa4a956676c770407bf15cc`. It is included unchanged under the adjacent upstream licence.

The grammar is loaded with newline-aware parsing and added to syntect’s default syntax set at highlighter initialisation. No external files or network access are required at runtime.
